👨‍💻 Sobre mim
Sou Desenvolvedor Web Full Stack e gosto de transformar ideias em produtos digitais bonitos, performáticos e úteis.
- ⚡ Desenvolvo interfaces modernas, responsivas, acessíveis e com microinterações.
- 🔐 No back-end, trabalho com APIs REST, autenticação, integrações e regras de negócio.
- 📱 Também construo experiências mobile com React Native e arquiteturas offline-first.
- ☁️ Utilizo serviços cloud e plataformas como AWS e Firebase quando fazem sentido para o projeto.
- 🧠 Tenho interesse constante em IA aplicada, automações e produtos digitais inteligentes.
- 🤝 Aberto a oportunidades, projetos freelance e colaboração com outros devs.
Código bom não é só o que funciona. É o que continua fazendo sentido depois do deploy.
